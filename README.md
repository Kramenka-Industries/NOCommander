# NOCommander
This is a BepInEx mod for Nuclear Option. It implements RTS-style gameplay features and is allowing commanding a Unit in 3D. Mainly intended to be played  in Escalation or Terminal Control game modes. 

## Disclaimer

- I can't write C# so every line of code in this mod was generated by an LLM. My contribution was mostly limited to the gameplay logic and design ideas.
- This mod was initially intended for personal use only but it turned out surprisingly well so I figured I might as well share it. Either for people who simply want to play it and for anyone who wants to avoid some of the roadblocks I encountered while making it.
- Because of that this mod is licensed under the Unlicense, basically the least restrictive license I could find.
- Right now this mod is not balanced whatsoever. That's definetly on the to-do but I first need to implement all major features I would like. In essence, this is basically a cheat mod right now.

## Core


- RTS-style camera and interface with custom UI (still needs some work)
- Free camera with 3D unit selection and movement orders in 3D
- Pinning units to the UI, stopping units, preventing units from using roads, returning control to the AI, and deleting units

## Depot Spawning

- Buy ground units using the faction money pool or deploy vehicles from the faction reserve
- Vehicles are organized by their base-game categories in the UI
- Optional rally points for spawned vehicles
- Spawn queue
- Faction reserve system that allows certain unit types to be held back after being produced by factories

## Supply Heli

- Custom supply runs using cargo-capable helicopter
- Configurable cargo loadouts
- Support for landing deliveries and parachute airdrops
- Landing-zone selection in 3D

## Air Command

- Dispatch aircraft with customizable loadouts on specific missions.

### Current mission types:

- Air Superiority
- AWACS/Jammer
- CAS
- ARAD
- Strike

### Mission behavior

- Mission types use varying degrees of custom logic:
  - AWACS and Air Superiority aircraft will try to remain within their assigned area while targeting anything within range (blue circle).
  - CAS, ARAD, and Strike missions will only attack targets within their assigned area (red circle).
- Some mission types offer additional options, such as saturation attacks for ARAD missions.
- Missions already in progress can be edited through the Air Command menu.

### Aircraft handling

- Aircraft spawned through Supply Heli or Air Command are taken from the faction reserve when possible.
- If no suitable airframe is available, one is purchased using the faction money pool.
- Successfully returning aircraft either restore the airframe to the reserve or refund the money spent on it.

## Camera

- Follow the selected unit
- Center on the selected unit
- POV camera that moves with the selected unit and allows snapping to the head position of available crew members

## Map

- Movable tactical minimap
- LMB moves the camera to the selected position
- Units can be selected through the tactical map

## Unit Systems

- Toggle compatible radar systems on or off
- Display radar coverage on the map with an adjustable target altitude
- Toggable: Force Jacknifes to repair the nearest valid target instead of he highest priority one
- Relocate containers using nearby tractors or flatbeds
- Request naval resupply missions for selected naval units

## Naval

- Purchasable naval units

## Experimental

- Heavily WIP tool for automatically building SAM sites via jacknifes with landing pads for ammo deliveries. Intended to be used later by enemy AI for balancing purpose.

## Requirements

- Nuclear Option
- BepInEx 5
- BepInEx Configuration Manager

## Installation

Download `NuclearOptionCommander.dll` from the latest release.
Place it in your NuclearOption/BepInEx/plugins folder.
